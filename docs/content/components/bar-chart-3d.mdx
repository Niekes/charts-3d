    ```package-install
    npx shadcn@latest add niekes/charts-3d/bar-chart-3d
    ```
  </Tab>
  <Tab value="Manual">
    Install the dependencies:

    ```package-install
    npm install d3-3d d3-array
    ```

    Copy [chart-3d](/docs/components/chart-3d) into `components/ui/chart-3d.tsx`, then this code into `components/ui/bar-chart-3d.tsx`:

    <include>../../../registry/new-york/ui/bar-chart-3d.tsx</include>

    Update the import paths to match your project setup.
