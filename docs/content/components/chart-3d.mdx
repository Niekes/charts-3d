import Chart3DDemo from "@/docs/examples/chart-3d-demo"

`chart-3d` is the core the other charts install with it. Use it directly to draw your own d3-3d shapes in the chart box: `useChart3D` hands you the camera, `Axes3D` draws the box and `shade` lights a face.

## Installation

<Tabs items={["CLI", "Manual"]}>
  <Tab value="CLI">
    ```package-install
    npx shadcn@latest add niekes/charts-3d/chart-3d
    ```
  </Tab>
  <Tab value="Manual">
    Install the dependencies:

    ```package-install
    npm install d3-3d d3-array
    ```

    Copy the code into `components/ui/chart-3d.tsx`:

    <include>../../../registry/new-york/ui/chart-3d.tsx</include>

    Update the import paths to match your project setup.

  </Tab>
</Tabs>
