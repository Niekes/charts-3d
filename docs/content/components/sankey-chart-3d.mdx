Flows that cross pass one another in depth, so a crossing reads the same from every side: they share the depth of a flow in lanes, one behind the other, and the lane that carries less passes in front. A flow narrows into its lane on its way to the crossing and is whole again at the next node; where that way would be too steep, it keeps to its lane from node to node. Pointing at a flow lights it and its two nodes, pointing at a node lights its flows and the nodes at their other ends, and everything else fades until the pointer leaves the chart.

## Installation

<Tabs items={["CLI", "npm", "Manual"]}>
  <Tab value="CLI">
    ```package-install
    npx shadcn@latest add niekes/charts-3d/sankey-chart-3d
    ```
  </Tab>
  <Tab value="npm">
    ```package-install
    npm install @niekes/charts-3d
    ```

    Import `SankeyChart3D` from `@niekes/charts-3d`, and add the package to the sources of Tailwind, see [Installation](/docs/installation#from-npm).

  </Tab>
  <Tab value="Manual">
    Install the dependencies:

    ```package-install
    npm install d3-3d d3-array lucide-react
    ```

    Copy [chart-3d](/docs/components/chart-3d) into `components/ui/chart-3d.tsx`, then this code into `components/ui/sankey-chart-3d.tsx`:

    <include>../../../registry/new-york/ui/sankey-chart-3d.tsx</include>

    Update the import paths to match your project setup.

  </Tab>
</Tabs>

`animationDuration` of the container.
