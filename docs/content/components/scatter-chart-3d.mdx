## Installation

<Tabs items={["CLI", "npm", "Manual"]}>
  <Tab value="CLI">
    ```package-install
    npx shadcn@latest add niekes/charts-3d/scatter-chart-3d
    ```
  </Tab>
  <Tab value="npm">
    ```package-install
    npm install @niekes/charts-3d
    ```

    Import `ScatterChart3D` from `@niekes/charts-3d`, and add the package to the sources of Tailwind, see [Installation](/docs/installation#from-npm).

  </Tab>
  <Tab value="Manual">
    Install the dependencies:

    ```package-install
    npm install d3-3d d3-array
    ```

    Copy [chart-3d](/docs/components/chart-3d) into `components/ui/chart-3d.tsx`, then this code into `components/ui/scatter-chart-3d.tsx`:

    <include>../../../registry/new-york/ui/scatter-chart-3d.tsx</include>

    Update the import paths to match your project setup.

  </Tab>
</Tabs>
